# features/

Modül bazlı iş mantığı (feature) klasörü. Her modül kendi tiplerini,
yardımcılarını ve ileride Supabase'e özel mantığını burada barındırır.

Şu an domain tipleri `src/types`, mock veriler `src/mock`, veri erişimi ise
`src/services` altında tutulur. `auth` feature'ı örnek yapı olarak hazırlanmıştır;
diğer modül klasörleri ileride genişletilmek üzere ayrılmıştır.
